## 현재 상태

`Study-05`는 "AI 공감 다이어리"입니다. 사용자가 오늘 있었던 일을 한 줄 쓰면 서버가 OpenRouter 무료 모델로 감정을 분석하고 공감·위로 메시지를 돌려준 뒤 저장합니다.

- 저장소 루트는 상위 폴더 `D:\study\inflearn\VibeCoding`이고, `Study-01`~`Study-05`가 각각 독립된 프로젝트입니다. 명령은 이 폴더 안에서 실행합니다.
- `Study-05/.gitignore`가 `.env`, `node_modules/`, `data/`를 제외합니다. 필요한 환경 변수 목록은 키 없는 `.env.example`에 있고, 새 환경 변수를 추가하면 여기에도 넣습니다.

## 명령어

- `npm install` → `npm start`(또는 `npm run dev`로 파일 변경 시 자동 재시작) → http://127.0.0.1:3000 (PDF 요약 화면은 `/pdf`). `start.bat`은 필요하면 `npm install`을 한 뒤 서버를 띄우고 브라우저를 엽니다.
- `npm test`: `node --test`로 `tests/*.test.js`를 실행합니다. OpenRouter는 가짜 `chat`/`fetchImpl`로 대신해 실제 호출을 하지 않습니다. 파일 하나만: `node --test tests/analyzer.test.js`.
- 손으로 API를 시험할 때 Git Bash `curl -d`로 한글 JSON을 보내면 UTF-8로 가지 않으므로 Node `fetch`나 `curl -d @파일`을 씁니다.
- 백그라운드로 띄운 서버는 끝나면 종료합니다(포트 3000 확인).
- `node scripts/pdf-live-check.js [short|long]`: 켜 둔 서버로 PDF 요약을 실제로 시험합니다(실제 OpenRouter 호출, 하루 무료 한도 사용. 자동 테스트 아님).

## 구조

- 화면은 루트 `index.html` 단일 파일(인라인 CSS·JS)이며 프런트엔드 담당 영역입니다. 서버가 `GET /`에서 이 파일만 제공하고(루트 폴더를 정적 제공하지 않음, `.env` 노출 방지), `file://`로 열면 API를 부르지 않고 `no-cors` 요청으로 서버가 켜졌는지만 확인해 `http://127.0.0.1:3000/`으로 이동합니다(꺼져 있으면 `start.bat` 안내 + 5초 간격 자동 재확인, 최대 10분). 이 이동 주소는 3000 고정이라 `PORT`를 바꾸면 그 주소를 직접 열어야 합니다(꺼짐 안내에 한 줄 표시). API는 같은 출처 상대 경로로만 부릅니다. 새 일기를 보내기 시작하면 직전 결과 카드·위기 안내 상자를 숨기고(직전 일기의 109 안내는 목록 항목에 남음), 취소·화면 시간 초과 뒤에는 1.5초 후 `GET /api/entries`로 목록을 조용히 맞춰 서버가 이미 저장한 일기를 끼워 넣습니다(새 항목만 추가, 포커스·상태 문구 변경 없음). 멈춘 일기가 저장된 것으로 확인되면 입력란 아래에 한 줄 안내를 띄우고, 입력란 글이 그 일기와 같으면(앞뒤 공백 무시) 중복 전송을 막으려고 비웁니다(그사이 고쳐 쓴 글은 그대로 둠).
  - 글자 수는 서버와 같은 코드 포인트 기준 300자(`[...text].length`)로 세고 자릅니다(한글 조합 중에는 자르지 않음). `entry.crisis`가 true면 결과 카드 위(제목 + 전화 링크 중심의 짧은 상자)와 목록 항목에 109/1577-0199 안내를 보여 줍니다. empathy·comfort는 `setTextKeepingNumbers`로 텍스트 노드만 넣고 "1577-0199" 같은 하이픈 번호를 `.nowrap`으로 묶어 줄바꿈으로 갈라지지 않게 합니다. `DAILY_LIMIT`·`CONTENT_BLOCKED`·`AI_AUTH_ERROR`·`FORBIDDEN_ORIGIN`에는 재시도 버튼을 두지 않습니다.
  - `tests/qa-gaps.test.js`가 `describeError`를 떼어 DOM 없이 실행하므로, 이 함수는 바깥 변수·함수를 참조하지 않고 문자열에 짝 안 맞는 중괄호를 넣지 않습니다.
- `server.js`: 진입점. `import "./src/env.js"`를 **첫 번째 import**로 둬야 `.env`가 `config.js`에 반영됩니다. `127.0.0.1`(`HOST`)·`3000`(`PORT`)에서 받고, 시작할 때 설정한 모델이 OpenRouter 모델 목록에 있는지 확인해 없으면 경고만 남깁니다(목록 조회는 무료 한도를 쓰지 않음). `createApp`에 `hostNames: ["127.0.0.1", "localhost", HOST]`를 넘깁니다.
- `src/app.js`: 라우팅·검증·공통 오류 처리(`createApp`에 store·analyze를 주입). 오류는 항상 `{ error: { code, message } }`.
  - `GET /` → index.html(`X-Frame-Options: DENY`, `Content-Security-Policy: frame-ancestors 'none'`로 다른 사이트의 iframe 삽입 차단. CSP에 다른 지시어를 넣으면 인라인 스크립트·Google Fonts가 막히므로 넣지 않음), `GET /favicon.ico` → 204, `GET /api/health` → `{ ok, model, hasApiKey }`, `POST /api/entries` `{ text }`(`Content-Type: application/json` 필수, 앞뒤 공백 제거 후 코드 포인트 1~300자, 본문 10kb) → `201 { entry }`(id를 분석 전에 만들어 `analyze(text, { signal, entryId })`로 넘김 — 위기 일기 고정 위로 문구를 id로 고름), `GET /api/entries` → 최신순 `{ entries }`, `DELETE /api/entries/:id` → 204 / 404.
  - Entry: `{ id, text, createdAt, emotion: { primary, label, intensity, keywords }, empathy, comfort, crisis, model }`. `crisis`(boolean)는 자해·자살 암시가 감지되면 true이고, 필드가 없던 예전 저장 일기는 응답할 때 false로 채웁니다.
  - 오류 코드: `INVALID_INPUT` 400(본문 JSON 깨짐·10kb 초과·Content-Type이 JSON 아님·잘못된 압축 본문 등 본문 파서의 4xx 포함, 스택 로그 없음), `FORBIDDEN_ORIGIN` 403(다른 출처·로컬 아닌 Host), `NOT_FOUND` 404, `CONTENT_BLOCKED` 422(입력이 공급자 검열 403에 걸림), `CONFIG_ERROR` 500(키 없음), `AI_AUTH_ERROR` 502(401 키·402 크레딧·403 권한, 메시지가 원인별로 다름), `RATE_LIMITED` 429(일시적 한도), `DAILY_LIMIT` 429(계정 하루 무료 한도 소진, 재시도 무의미), `AI_TIMEOUT` 504, `AI_BAD_RESPONSE` 502, `UPSTREAM_ERROR` 502, `INTERNAL_ERROR` 500. 코드·상태·기본 메시지는 `src/errors.js`.
  - 응답 전에 클라이언트 연결이 끊기면(`res.on("close")`) `AbortController`로 진행 중인 AI 호출을 멈춥니다. 분석이 끝난 뒤라도 이미 끊겼으면 저장하지 않고, `store.add` 하는 사이에 끊겼으면 방금 저장한 일기를 지워 되돌립니다(로그 `CANCELLED by client …[; rolled back saved entry]`). 응답이 이미 전송 중일 때 끊기는 경우는 서버가 막을 수 없어 화면이 취소 뒤 목록을 다시 맞춥니다.
  - 로그: `[entries] OK 201 in …ms (model: …, calls: n/4[, fallback: 모델 코드 (상세); …], chars: 글자 수, emotion: primary/강도[, crisis, crisis-reply: model|retried|fallback][, language: english retried|english kept][, style: banmal fixed|banmal patched (retry reply|first reply|crisis retry)])`, 실패는 `[entries] FAILED in …ms (…): 코드 last: 상세`, 출처 차단은 `[security] blocked …`. 키와 일기 원문은 로그에 남기지 않습니다.
- `src/security.js`: CORS는 열지 않습니다(화면은 서버가 주는 같은 출처에서만 API를 부름). ① 모든 요청의 `Host`가 `127.0.0.1`·`localhost`·`HOST` 값 + 실제 포트가 아니면 403 `FORBIDDEN_ORIGIN`(DNS 리바인딩 차단). ② `/api/*`에 `Origin`이 있는데 그 자기 출처(`http://<허용 호스트>:<포트>`)가 아니면 403 `FORBIDDEN_ORIGIN`. `Origin: null`(file://·sandbox iframe)도 거부. `Origin`이 없는 요청(curl 등)은 허용합니다. 403 문구는 실제 포트로 "http://127.0.0.1:<PORT> 에서 열어 주세요"라고 안내합니다.
  - 화면의 file:// 이동 주소는 `http://127.0.0.1:3000/` 고정이라 `PORT`를 바꾸면 file://로 열어도 서버를 찾지 못합니다. 이때는 `http://127.0.0.1:<PORT>/`를 브라우저에서 직접 엽니다.
- `src/diary.js`: 입력 검증, 시스템 프롬프트(**위기 판단 절을 맨 앞에**: 간접 신호 목록(유서·작별 편지·물건 나눠 주기·옥상/난간·바다/파도·영원히 잠들기·수단·보험금·"이제 끝내야겠다"·오타 변형)과 "애매하면 true", 마지막 인사·"그동안 고마웠다"·"마지막으로 하고 싶던 일", 반려동물·아이·물건 맡길 사람 구해 둠·통장/비밀번호 적어 둠 + 홀가분/다 정리됨을 간접 신호로 넣고 "긍정 낱말(홀가분·고마움·평온)이 신호를 지우지 않는다"를 명시, 위기 답 금지 표현(당연·자연스러운·그럴 수 있어요·이해가 돼요·동조·다행이에요·좋은 하루·용기/좋은 결정으로 칭찬·안도 동조·수단·장소 되풀이)). 해요체만·반말 2인칭·당신 금지, 사용자 1인칭(내가·내)도 옮기지 말고 높임으로("내가 한 일" → "직접 하신 일"), 한국어만, 원문 사실·인물 관계 유지, 짧은 입력은 강도 2, 지시문 입력은 메타 답변 금지, keywords는 의미를 옮긴 감정·상황 낱말, 예시 2개(일상·간접 위기), 원문은 `<diary>…</diary>`, JSON만이고 **`crisis`가 첫 필드**), 응답 파싱(코드블록·앞뒤 설명·끝 쉼표 허용) → 정규화(`primary` 목록 밖은 별칭 보정 후 `mixed`, `label`은 서버 고정 표 `EMOTION_LABELS`, `intensity` 1~5, `keywords` 1~3개, empathy·comfort에 한글이 없으면 형식 오류). 형식 오류·잘린 답이면 1회 재요청, 그래도 안 되면 `AI_BAD_RESPONSE`.
  - 반말 후처리 (위기가 아닌 일기만 재요청. 위기 일기는 아래 '위기' 참고): ① empathy·comfort에 반말 2인칭(`hasBanmal`: 네가·니가·너는·너의·너를·너랑·너희·넌·널·너·네게·너처럼·너보다·너까지·너밖에·너조차·너에게서, 소유격 "네 ○○"(문장 가운데, 또는 첫머리의 "네 덕분/잘못/탓/편/마음…"). 대답 "네,"·"네 번째"·"네 편의 영화" 같은 수는 제외, 따옴표 안은 보지 않음)이 있고 원문에는 없거나, ③ 사용자를 1인칭으로 되풀이(`hasFirstPerson`: 따옴표 밖 "내가/내 ○○/나를/나의/나는/나도/나만/나 때문/나 자신". "용기를 내 보세요"·"누나 때문"·"하나만"·"나만의"·"나무" 제외)하거나, ② 문장 끝 반말 어미(`hasBanmalEnding`: "대단해.", "~야.", "~했니?", "~겠다." 등. 각 문장 마지막 낱말만 보고 "~습니다"·"~구나"는 제외)가 있으면 1회 다시 요청합니다. 재요청은 직전 답을 넣지 않은 **새 대화**(시스템 프롬프트 + `STYLE_RETRY_NOTE`의 더 강한 높임·어미 지시, temperature +0.3)입니다. 직전 답을 넣으면 모델이 그대로 복사했기 때문입니다(실제 nemotron). 다시 받은 답도 반말이거나 예산이 없거나 실패하면 서버가 `softenBanmal`로 2인칭을 **"본인"으로 바꿉니다**(지우면 뜻이 바뀜: "너만 힘든 게 아니에요" → "본인만 힘든 게 아니에요", "네 잘못" → "본인 잘못", "네가 한 말" → "본인이 한 말", 너를/널 → 본인을, 너랑/너와 → 본인과, 너한테/네게 → 본인에게, 너희 → 여러분, 부르는 말 "너,"만 지움. 따옴표 안('…' "…" 「…」 『…』)은 그대로, style `banmal patched`). "당신"은 3인칭 높임("엄마는 항상 당신을 응원하셨어요")으로도 쓰여 감지·보정하지 않습니다(프롬프트에서만 금지). 2인칭 앞에 3인칭 주어("친구가", "엄마는", "팀장님께서". "오늘은"·"그건" 같은 시간·지시 주제어 제외)가 있는 문장은 "본인"이 그 주어를 가리키게 되므로 **문장을 통째로 빼고**(다른 문장이 남을 때만), 뺄 수 없으면(한 문장짜리) 목적어·여격·동반 2인칭(너를·널·너한테·너에게·네게·너에게서·너랑·너와·너하고)만 지웁니다("아빠는 너를 믿고 계세요" → "아빠는 믿고 계세요"). 주어(네가·너는)·소유격(네·너의)·한정(너만·너밖에…)·비교(너처럼·너보다)는 지우면 뜻이 바뀌어 "본인"을 유지합니다(남은 한계: "친구가 네가 한 말에" → "친구가 본인이 한 말에"). 띄어 쓴 "너 때문/덕분/탓"은 "본인 때문", "너 자신"은 "자신"으로 바꿉니다. "본인이 본인을"은 뒤쪽을 "자신을"로 바꿉니다. 1인칭은 기계로 고치지 않습니다. 반말 어미는 오변환 위험 때문에 기계로 고치지 않습니다. 모든 답에서 문장 끝 "~구나" → "~군요"(`fixBanmalEndings`), "바래요/바랬어요" → "바라요/바랐어요"(`fixSpelling`). 사용자 원문은 고치지 않습니다. 규칙은 `tests/qa-recheck.test.js`·`tests/qa-final.test.js`·`tests/style-keywords.test.js`에 고정되어 있습니다.

  - 입력은 쪽이 바뀔 때마다 `[p.N]`, 빠진 곳은 `…(중략)…`. 문서는 `<document>…</document>`로 감싸고 본문 안의 document 태그는 지웁니다. 시스템 프롬프트는 영어(모델이 지시를 더 잘 지킴)이고 한국어 해요체 출력·문서 안 지시 무시·원문에 없는 사실 금지·`[p.N]` 근거 쪽만·일부 입력이면 전체 단정 금지를 넣고, 다른 주제 예시 1개를 둡니다. 짧은 문서(2,000자 미만)는 요점 1~3개, 그 밖 3~7개. 필드 길이는 상한보다 짧게 요구합니다(max_tokens 안에 들어오게).
  - 호출: `chatWithFallback`(다이어리와 같은 모델 순서·재시도·쿨다운), temperature 0.3, `PDF_SUMMARY_MAX_TOKENS`(기본 3000. 한국어 JSON이 2,000토큰 가까이 나올 수 있어 PRD 값 2000보다 늘림), 채팅 1회 35초, rerank 15초, 문서 1건 호출 4회(rerank 포함)·90초(`startedAt`부터 세므로 추출 시간 포함). 형식 오류(JSON 아님·필수 필드 없음·oneLine/overview/요점에 한글 없음·keywords 없음·`finish_reason: length`)면 직전 답 없는 새 대화 + 강조 지시 + temperature +0.2로 1회 재요청(`retry: format (json|korean|missing|length)`), 그래도 안 되면 `AI_BAD_RESPONSE`(재요청이 `DAILY_LIMIT`·인증·검열로 실패하면 그 코드).
  - 정규화: diary.js의 `extractJson`(코드블록·앞뒤 설명·끝 쉼표 허용). 상한(oneLine 120·overview 600·요점 1~7개 200자·섹션 0~8개 제목 40/요약 300·키워드 1~8개 20자 중복 제거)을 넘으면 문장 끝(뒤쪽 절반 안)이나 `…`로 자르고, 텍스트 안 `[p.N]` 표시는 지웁니다. `pages`는 요약 입력에 실제로 들어간 쪽만 남기고(요점은 쪽 목록, 섹션은 `[시작, 끝]` 양 끝 모두), 남는 게 없으면 필드를 뺍니다. `notices`는 경로 문구(`METHOD_NOTICES`) + `documentNotices`로 3개까지.
- rerank API(`src/openrouter.js`의 `createRerank`): `POST /api/v1/rerank` `{ model, query, documents, top_n }`. OpenRouter 문서(`CreateRerankResponseBody`)상 응답은 `{ id?, model, provider?, results: [{ index, relevance_score, document? }], usage? }`이고 `relevanceScore`도 받습니다. index가 범위 밖이거나 점수가 숫자가 아니면 형식 오류. 문서 수 상한은 문서에 없어 128로 가정합니다. **2026-10-28에는 계정 하루 한도가 소진되어 성공 응답을 실측하지 못했습니다**(429 `free-models-per-day` 응답만 확인). 이 모델은 `/api/v1/models`에는 안 나오고 `?output_modalities=all`에만 나옵니다(엔드포인트 1개, 질의+문서 10,240토큰). 시작 시 모델 확인도 이 목록을 씁니다. 한도가 풀리면 서버를 켜고 `node scripts/pdf-live-check.js`(짧은 한글 1건 full + 긴 영문 30쪽 1건 rerank, 실제 호출 3회 정도)로 확인합니다.
- `src/pdf.js`: 라이브러리는 `unpdf`(의존성 0개, PDF.js 서버리스 빌드를 묶은 순수 JS. `pdfjs-dist`는 네이티브 선택 의존성 `@napi-rs/canvas`를 함께 설치해 고르지 않음). `isEvalSupported: false`·XFA 끔. 앞 `PDF_MAX_PAGES`쪽·`PDF_MAX_TEXT_CHARS`자(코드 포인트)까지 읽고 `truncatedPages`·`truncatedChars`로 표시, 쪽마다 `{ page, text }`(줄은 `\n`, 줄 간격이 그 쪽 중앙값보다 넓으면 문단 `\n\n`). 같은 줄 항목은 간격이 벌어졌을 때만 공백(한글끼리는 0.3em, 그 밖 0.2em), 한 글자씩 띄운 제목 줄("목 차")은 붙입니다. 시간 상한은 타이머 + 쪽마다 시각 확인(PDF.js가 같은 스레드에서 돌아 타이머가 늦을 수 있음). 글꼴을 넣지 않고 미리 정의된 CJK CMap(UniKS-UCS2-H·KSCms-UHC-H 등)을 쓰는 PDF는 `vendor/pdfjs-cmaps/`(pdfjs-dist 6.4.299의 `.bcmap` 전체 + 라이선스, 출처는 그 폴더 README)를 `LocalBinaryDataFactory`로 읽어 처리합니다(CMap만 읽고 파일 이름 형식 검사). unpdf를 올려 PDF.js 버전이 바뀌면 같은 버전의 cmaps로 바꿉니다. 문서 안내 문구는 `documentNotices`.

## LLM 연동 (OpenRouter)

- 기본 모델 `nvidia/nemotron-3.5-super-vl:free` → 대체 `nvidia/nemotron-3-ultra-550b-a55b:free` → `nvidia/nemotron-3.5-lightning:free` → `google/gemma-4-31b-it:free`. 2026-10-28에 gemma 둘은 거의 매번 429, lightning은 200 헤더 뒤 본문이 90초 넘게 오지 않아(대기열 정체) 일기가 `AI_TIMEOUT`으로 실패했고, 같은 프롬프트로 super-vl·ultra가 1~2초에 형식에 맞는 해요체 JSON을 돌려줘 순서를 바꿨습니다. 무료 모델 상태는 자주 바뀌므로 느려지면 `/api/v1/models` 조회와 1회 시험 호출로 다시 고릅니다. `thinkingmachines/inkling*:free`는 "agentic harnesses 전용" 403이라 쓸 수 없습니다. `OPENROUTER_MODEL`, `OPENROUTER_FALLBACK_MODELS`(쉼표 구분)로 바꿉니다. 응답의 `entry.model`이 실제 응답한 모델입니다.
- 원래 요구는 meta-llama `:free` 모델이었지만 2026-10-27 기준 OpenRouter에 무료 llama가 없습니다(`meta-llama/llama-3.3-70b-instruct:free` 등은 엔드포인트 0개, 호출하면 404 "unavailable for free"). 키는 무료 등급이라 유료 llama는 402가 납니다. 무료 llama가 다시 생기면 `OPENROUTER_MODEL`로 지정합니다.
- 추론 토큰도 `max_tokens`(기본 1000)에 포함되므로 `reasoning: { effort: "none" }`을 보냅니다(`AI_REASONING_EFFORT`, 비우면 보내지 않음). 추론이 필수인 모델로 바꾸면 비웁니다.
- 무료 모델은 **계정 전체**에 하루 요청 수 제한(크레딧 없을 때 50회)이 있고 실패한 요청도 포함됩니다. Google AI Studio의 gemma 무료 모델은 자주 "temporarily rate-limited upstream" 429를 내므로 그때는 nvidia 모델로 넘어갑니다.
- API 키는 서버(`.env`)에서만 읽고 응답·로그에 넣지 않습니다.

## 작성 규칙

- 코드(식별자·문자열)는 영어, 주석과 이 문서는 한국어로 씁니다.
- 새 파일 맨 위에는 `작성일시: YYYY-MM-DD HH:MM` 주석을 넣습니다.
- `.bat` 파일은 CRLF 줄바꿈 + CP949 인코딩으로 저장합니다.
