`questions.js`의 퀴즈 문제에서 '가장', '최초', '최대' 같은 모호한 표현을 찾고, 문제마다 어떤 기준을 명시해야 하는지 알려줘.

## 검증 대상
- 입력된 카테고리: `$ARGUMENTS`
- 위 값이 비어 있으면 **전체 문제**를 검증한다.
- 값이 있으면 앞뒤 공백과 따옴표를 제거한 뒤, 각 문제의 `category` 값과 같은 문제만 검증한다.
  - 일치하는 카테고리가 없으면 검증하지 말고, `questions.js`에 있는 카테고리 목록을 보여준 뒤 다시 입력해 달라고 안내한다.
- `question` 문구를 기본으로 검사하고, `options`·`explanation`에 같은 표현이 있으면 참고로 따로 표시한다.

## 찾을 표현
가장, 최초, 최대, 최소, 최고, 최저, 최장, 최단, 제일, 처음, 유일

- '최고(最高) 학부'처럼 순위가 아니라 지위를 뜻하는 경우는 "지위 의미"로 구분해서 표시한다.

## 표현별로 명시해야 할 기준
찾은 표현이 무엇을 비교하는지 보고, 아래 예시처럼 필요한 기준을 구체적으로 제안한다.

| 표현 | 비교 대상 | 명시해야 할 기준 예시 |
|------|-----------|------------------------|
| 가장 큰 / 최대 / 최소 | 크기 | 면적, 부피, 지름, 질량, 인구 중 무엇인지 |
| 가장 긴 / 최장 / 최단 | 길이 | 전체 길이, 본류 기준, 측정 방식 |
| 가장 높은 / 최고 / 최저 | 높이·수치 | 해발고도, 기저부부터 높이, 기온 등 |
| 최초 / 처음 / 가장 먼저 | 순서 | 무엇의 최초인지(발명, 발표, 상용화 등), 지역 범위 |
| 유일 | 개수 | 분류 범위, 시점 |
| 가장 많은 / 제일 | 양·순위 | 측정 단위(부피비, 질량비 등), 시점 |

## 점검 기준 (CLAUDE.md "퀴즈 문제 교차 검증 가이드라인")
각 문제마다 확인한다.
1. **기준:** 측정 기준이 명시되어 있는가? (예: 면적 기준, 길이 기준, 해발고도 기준)
2. **시점:** 시간이 지나면 바뀔 수 있는 정보라면 시점이 명시되어 있는가? (예: 2024년 기준)
3. **범위:** 지리적·분류적 범위가 한정되어 있는가? (예: 태양계에서, 아프리카에서)
4. **정답 유일성:** 정답이 하나뿐인가? 다른 해석이 가능하면 어떤 해석인지 적는다.
- 의심스러운 사실은 2개 이상의 출처로 교차 확인하고, 논란이 있으면 주류 학설을 기준으로 판단한다.

## 출력 형식
1. 맨 위에 검증 범위를 적는다. (예: "검증 범위: 세계지리" 또는 "검증 범위: 전체")
2. 아래 표로 보여준다.

| ID | 카테고리 | 문제 | 표현 | 기준 | 시점 | 범위 | 명시해야 할 기준 | 판정 |
|----|----------|------|------|------|------|------|------------------|------|

- 기준·시점·범위 칸: 명시되어 있으면 그 내용을, 없으면 "없음", 필요 없으면 "불필요"라고 적는다.
- 명시해야 할 기준 칸: 빠진 기준을 구체적으로 적는다. 이미 충분하면 "-"로 적는다.
- 판정: ✅ 적합 / ⚠️ 보완 필요 (이유와 수정 문구 제안)

3. `options`·`explanation`에서만 발견된 표현은 별도의 참고 표로 보여준다.
4. 마지막에 요약을 덧붙인다: 검증한 문제 수, 모호한 표현이 들어간 문제 수, 보완 필요 문제 수.

## 주의
- 이 명령은 점검만 한다. `questions.js`를 수정하지 말고, 수정은 사용자가 요청할 때만 한다.
