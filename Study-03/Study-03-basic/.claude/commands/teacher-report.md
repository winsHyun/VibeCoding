학생에게 나눠 줄 개인 성적표를 만들어줘.

## 입력값
- 전체 입력: `$ARGUMENTS`
- `--period <기간>`이 있으면 떼어 내 기간으로 쓴다. 비어 있으면 `all`. 허용 값은 `.claude/commands/teacher-collect.md`의 "기간 값"을 따른다.
- 남은 값이 학생 이름이다. (따옴표 제거) `all`이면 기간 안에 기록이 있는 모든 학생의 성적표를 만든다.
- 이름이 비어 있으면 실행하지 말고 사용 예(`/teacher-report 민수`, `/teacher-report all --period week`)를 보여준다.
- 데이터에 없는 이름이면 실행하지 말고, 데이터에 있는 학생 목록과 비슷한 이름을 보여준다.

## 준비
- `.claude/commands/teacher-collect.md`의 "공통 기준"을 읽고 그대로 따른다.
- `teacher-data/class-history.json`이 없으면 `/teacher-collect`를 먼저 실행하라고 안내하고 멈춘다.

## 만들 파일
- 경로: `teacher-data/reports/<학생이름>-YYYYMMDD.md` (날짜는 실행일. 폴더가 없으면 만든다)
- 파일 이름에 쓸 수 없는 문자(`\ / : * ? " < > |`)는 `_`로 바꾼다.
- 같은 이름의 파일이 이미 있으면 덮어쓰기 전에 사용자에게 확인한다. (`all`이면 겹치는 파일 목록을 한 번에 보여주고 한 번만 확인)

## 성적표 내용 (파일 안)
```markdown
# 퀴즈 성적표 - <학생이름>
기간: <시작일> ~ <종료일> · 작성일: <실행일>

## 한눈에 보기
| 항목 | 내 기록 | 학급 평균 |
|------|---------|-----------|
| 플레이 수 | | |
| 평균 정답률 | | |
| 평균 응답 시간 | | |
| 최장 연속 정답 | | (학급 평균 대신 "-") |

## 카테고리별 정답률
| 카테고리 | 내 정답률 | 학급 평균 | 그래프 |
(그래프는 10%마다 █ 한 칸, 예: 70% → ███████)

## 이렇게 성장했어요
처음 5게임과 최근 5게임 정답률 비교, 최고 기록(모드·조건과 함께)

## 잘하는 점 / 더 연습할 점
- 잘하는 점: 정답률이 가장 높은 카테고리, 학급 평균보다 높은 항목
- 더 연습할 점: 정답률이 가장 낮은 카테고리와 추천 연습 (모드·카테고리·난이도·횟수)

## 선생님 한마디
(비워 둔다. 선생님이 직접 적는다)
```

## 작성 규칙
- **다른 학생의 이름, 점수, 순위는 넣지 않는다.** 학급과의 비교는 학급 평균만 쓴다.
- 등수 대신 성장과 다음 목표를 중심으로, 학생이 읽기 쉬운 존댓말로 쓴다. 정답률이 낮아도 탓하는 표현은 쓰지 않는다.
- 기록이 3회 미만이면 "기록이 더 쌓이면 정확한 분석을 할 수 있어요"를 넣고, 강점·약점은 단정하지 않는다.
- 표본이 적은 카테고리는 그래프 대신 "아직 기록이 적어요"로 적는다.

## 출력 형식 (대화창)
1. 만든 파일 목록: 학생 | 파일 경로 | 평균 정답률 | 더 연습할 카테고리
2. 덮어쓰지 않고 건너뛴 파일이 있으면 그 목록
3. `all`이 아니면 만든 성적표 내용을 그대로 한 번 보여준다.

## 주의
- 만들거나 바꾸는 파일은 `teacher-data/reports/` 안의 성적표뿐이다. 소스 코드와 학급 데이터는 수정하지 않는다.
- 계산에 쓴 임시 스크립트는 스크래치패드에 만든다.
