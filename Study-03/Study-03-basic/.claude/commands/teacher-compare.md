지정한 학생들의 퀴즈 성적을 나란히 비교해줘.

## 입력값
- 전체 입력: `$ARGUMENTS`
- 공백으로 나눠 학생 이름 목록을 만든다. 띄어쓰기가 있는 이름은 따옴표로 묶어 입력한다. (예: `/teacher-compare "김 민수" 지은`)
- `--period <기간>`이 있으면 떼어 내 기간으로 쓴다. 비어 있으면 `all`. 허용 값은 `.claude/commands/teacher-collect.md`의 "기간 값"을 따른다.
- 학생이 1명이면 그 학생과 **학급 평균**을 비교한다. 2~5명이면 학생끼리 비교하고 학급 평균 열을 함께 보여준다.
- 학생이 0명이거나 6명 이상이면 실행하지 말고 사용 예(`/teacher-compare 민수`, `/teacher-compare 민수 지은 서준`)를 보여준다.
- 데이터에 없는 이름이 있으면 실행하지 말고, 데이터에 있는 학생 목록과 비슷한 이름(공백·대소문자만 다른 이름)을 보여준다.

## 준비
- `.claude/commands/teacher-collect.md`의 "공통 기준"을 읽고 그대로 따른다.
- `teacher-data/class-history.json`이 없으면 `/teacher-collect`를 먼저 실행하라고 안내하고 멈춘다.

## 보여줄 내용
### 1. 핵심 지표 비교
| 지표 | 학생1 | 학생2 | … | 학급 평균 |
|------|-------|-------|---|-----------|
| 플레이 수 | | | | |
| 평균 정답률 | | | | |
| 한국사 / 세계지리 / 과학 / 예술과 문화 정답률 | (카테고리마다 한 줄) | | | |
| easy / medium / hard 정답률 | (난이도마다 한 줄) | | | |
| 평균 응답 시간 | | | | |
| 최장 연속 정답 (최고) | | | | |
| 힌트 사용률 | | | | |
| 추세 | | | | |

- 줄마다 가장 높은 값에 **굵게** 표시한다. (응답 시간과 힌트 사용률은 낮은 값이 좋은 값)
- 학급 평균 열은 학급 전체 누적값으로 계산한다. (학생 평균의 평균이 아님)
- 표본 기준에 못 미치는 칸에는 "(표본 적음)"을 붙인다.

### 2. 같은 조건 점수 비교
비교 대상 학생이 **모두** 플레이한 (모드, 카테고리, 난이도) 조합만 골라 각자의 최고 점수와 정답률을 보여준다. 공통 조합이 없으면 "같은 조건으로 플레이한 기록이 없어 점수는 비교하지 않음"이라고 적는다.

| 모드·카테고리·난이도 | 학생1 최고 점수 (정답률) | 학생2 최고 점수 (정답률) | … |
|----------------------|--------------------------|--------------------------|---|

### 3. 정답률 변화
학생마다 게임 순서대로 정답률을 나열하고(최근 10게임까지), 처음 5게임 평균과 최근 5게임 평균을 적는다.

### 4. 학생별 강점과 약점
학생마다 한 줄씩:
- 강점: 학급 평균보다 가장 많이 높은 카테고리 (차이 %p)
- 약점: 학급 평균보다 가장 많이 낮은 카테고리 (차이 %p)
- 추천 연습: 약점 카테고리의 "카테고리별 도전" 모드와 난이도 (예: "과학 · easy부터")

### 5. 요약
비교 결과를 세 문장 이내로 정리한다. 기록이 적은 학생이 있으면 결론을 단정하지 않는다.
