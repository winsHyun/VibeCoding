`questions.js`에 새 퀴즈 문제를 1개 만들어 추가해줘.

## 입력값
- 카테고리: `$0`
- 난이도: `$1`
- 두 값 모두 앞뒤 공백과 따옴표를 제거한 뒤 사용한다.
- 카테고리는 `questions.js`에 이미 있는 `category` 값 중 하나여야 한다.
  - 현재 카테고리: 한국사, 세계지리, 과학, 예술과 문화 (파일을 읽어 실제 목록을 다시 확인한다)
  - '예술과 문화'처럼 띄어쓰기가 있는 카테고리는 따옴표로 묶어 입력한다. (예: `/quiz-add "예술과 문화" easy`)
- 난이도는 `easy`, `medium`, `hard` 중 하나여야 한다. 대소문자는 구분하지 않고 소문자로 저장한다.
- 값이 비어 있거나 위 목록에 없으면 문제를 만들지 말고, 사용법(`/quiz-add 과학 hard`)과 사용할 수 있는 카테고리·난이도 목록을 보여준 뒤 다시 입력해 달라고 안내한다.

## 문제 작성 규칙
### 형식 (기존 문제와 동일하게)
```js
    {
        id: 49,
        category: "과학",
        difficulty: "hard",
        question: "문제 문구",
        options: ["보기1", "보기2", "보기3", "보기4"],
        correctAnswer: 0,
        explanation: "정답 근거와 함께 짧은 설명"
    }
```
- `id`: 파일에 있는 가장 큰 `id` + 1 (배열 순서와 상관없이 `id` 값으로 계산한다)
- `options`: 보기는 정확히 4개, 중복 없이 작성한다. 길이와 형식(연도, 인물명 등)을 비슷하게 맞춘다.
- `correctAnswer`: 0~3 사이 값. 현재 파일의 정답 위치 분포를 세어 **가장 적게 쓰인 위치**에 정답을 둔다.
- `explanation`: 정답이 왜 맞는지 한두 문장으로 적고, 연도·수치가 있으면 함께 적는다.
- 들여쓰기는 공백 4칸, 문자열은 큰따옴표를 쓴다.

### 난이도 기준
- easy: 상식 수준
- medium: 관련 지식을 조금 알면 풀 수 있음
- hard: 세부 연도·인물·개념을 정확히 알아야 함
- 오답 보기가 너무 뻔해서 정답이 쉽게 드러나지 않게 한다. 특히 hard는 그럴듯한 오답을 넣는다.

### 중복 금지
- 기존 문제와 같은 내용을 묻지 않는다. 문구만 바꾼 문제도 중복으로 본다.
- 작성 전에 같은 카테고리의 기존 문제를 모두 읽고 겹치지 않는 주제를 고른다.

## 검증 가이드라인 (CLAUDE.md "퀴즈 문제 교차 검증 가이드라인") — 반드시 지킨다
추가하기 전에 아래 항목을 모두 확인하고, 하나라도 통과하지 못하면 문제를 고치거나 다른 문제로 바꾼다.
1. **정답이 하나뿐인가?** 다른 해석이 가능하면 조건을 문제에 명시한다. (예: 면적 기준, 2024년 기준)
2. **최상급 표현에 기준이 있는가?** '가장', '최초', '최대', '최고', '최장' 등을 쓰면 측정 기준을 명시한다. (예: 해발고도 기준, 지름 기준)
3. **시간과 범위가 명확한가?** 바뀔 수 있는 정보는 시점을 명시하고, 지리적·분류적 범위를 한정한다. (예: 태양계에서, 아프리카에서)
4. **교차 검증했는가?** 정답과 해설의 사실은 2개 이상의 출처로 확인한다. 논란이 있는 내용은 주류 학설을 기준으로 하거나, 논란이 없는 다른 주제를 고른다.
- 오답 보기 3개도 실제로 틀린 답인지 확인한다.

## 추가 방법
1. 위 규칙과 검증을 통과한 문제를 `questions.js`의 `quizQuestions` 배열 맨 끝(`];` 바로 앞)에 추가한다. 앞 항목 뒤에 쉼표가 빠지지 않게 한다.
2. 추가한 뒤 `node -e "require('./questions.js')"` 같은 방법으로 문법 오류가 없는지 확인한다. (전역 변수 선언 파일이므로 `node --check questions.js`로 확인해도 된다)
3. 다른 내용은 수정하지 않는다.

## 출력 형식
1. 추가한 문제를 표로 보여준다.

| ID | 카테고리 | 난이도 | 문제 | 보기 | 정답 위치 | 정답 |
|----|----------|--------|------|------|-----------|------|

2. 검증 결과를 표로 보여준다.

| 항목 | 결과 | 내용 |
|------|------|------|
| 정답 유일성 | ✅/⚠️ | |
| 최상급 기준 | ✅/불필요 | |
| 시간·범위 | ✅/불필요 | |
| 교차 검증 | ✅ | 확인한 출처 2개 이상 |
| 중복 여부 | ✅ | 비슷한 기존 문제 ID (없으면 "없음") |
| 난이도 적정성 | ✅ | 이 난이도로 판단한 이유 |

3. 정답 위치를 고른 이유를 한 줄로 적는다. (예: "추가 전 4번 위치가 0개여서 4번에 배치")
