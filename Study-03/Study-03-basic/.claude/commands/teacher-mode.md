선생님 모드의 명령들을 순서대로 실행해 학급 성적을 한 번에 정리해줘.

## 입력값
- 전체 입력: `$ARGUMENTS` (공백으로 나누고 따옴표 제거)
- `help`가 있으면 아무것도 실행하지 말고 아래 "명령 목록"과 사용 예만 보여준다.
- 기간: `all`, `week`, `today`, `YYYY-MM-DD~YYYY-MM-DD` 중 하나 (비어 있으면 `all`)
- `reports`가 있으면 5단계에서 모든 학생의 개인 성적표 파일을 만든다. 없으면 5단계는 건너뛴다.
- 그 밖의 값이 있으면 실행하지 말고 사용 예(`/teacher-mode`, `/teacher-mode week`, `/teacher-mode week reports`, `/teacher-mode help`)를 보여준다.

## 명령 목록
| 명령 | 하는 일 | 파일 생성 |
|------|---------|-----------|
| `/teacher-collect [경로]` | 학생 기록 파일을 합쳐 `teacher-data/class-history.json` 생성, 중복·이상 기록 정리 | O |
| `/teacher-overview [기간]` | 학급 요약, 학생별 성적표, 정답률 분포, 모드별 최고 기록, 주의 학생 | X |
| `/teacher-compare <학생...> [--period 기간]` | 학생 2~5명 나란히 비교, 또는 1명과 학급 평균 비교 | X |
| `/teacher-weakness [카테고리] [--period 기간]` | 학생 × 카테고리 정답률, 학급 약점, 보충 대상 학생, 문제 풀 보강 제안 | X |
| `/teacher-report <학생 \| all> [--period 기간]` | 학생에게 줄 개인 성적표 Markdown 파일 생성 | O |
| `/export-report <학생 \| all \| 파일> <csv \| pdf>` | 개인 성적표(.md)를 `teacher-data/exports/`에 CSV 또는 PDF로 저장 (`/teacher-mode`가 자동 실행하지 않음) | O |
| `/teacher-mode [기간] [reports]` | 위 명령을 순서대로 실행 (이 명령) | 단계에 따라 |

## 진행 규칙
- 아래 단계를 **순서대로** 진행한다. 각 단계는 해당 명령 파일(`.claude/commands/teacher-*.md`)을 읽고 **그 파일의 규칙과 출력 형식을 그대로** 따른다.
- 모든 단계에 같은 기간을 넘긴다. (1단계 collect는 기간과 상관없이 전체 기록을 모은다)
- 1단계가 실패하면(기록 파일 없음, 저장 검증 실패) 즉시 멈추고 "실패 보고"만 한다. 2~5단계에서 한 단계가 실패하면 그 단계에 실패 이유를 적고 다음 단계로 넘어간다.
- 같은 계산을 여러 번 하지 않도록, 1단계가 끝나면 학생별 지표(공통 기준의 "지표 정의" 전부)를 스크래치패드의 JSON 파일에 한 번 계산해 두고 2~5단계에서 재사용한다.

## 1단계: 기록 수집 (`teacher-collect.md`)
- 입력 경로는 기본값 `teacher-data/raw/`를 쓴다.
- 결과 중 "파일별 결과"와 "확인 필요"만 짧게 보여준다.

## 2단계: 학급 성적표 (`teacher-overview.md`)
- 1~5번 내용을 모두 보여준다.

## 3단계: 약점 분석 (`teacher-weakness.md`)
- 카테고리는 지정하지 않는다. (모든 카테고리 분석)

## 4단계: 학생 비교 (`teacher-compare.md`)
- 비교 대상은 자동으로 고른다.
  - 2단계 "주의가 필요한 학생"이 있으면: 그 학생들(최대 3명)을 **각각** 학급 평균과 비교한다. (1명 비교를 학생마다 실행)
  - 없으면: 평균 정답률 상위 1명과 하위 1명을 서로 비교한다.
  - 학생이 1명뿐이면 이 단계를 건너뛰고 이유를 적는다.
- 학생마다 "1. 핵심 지표 비교"와 "4. 강점과 약점"만 보여준다.

## 5단계: 개인 성적표 (`teacher-report.md`, `reports`가 있을 때만)
- `all`로 실행한다. 덮어쓸 파일이 있으면 `teacher-report.md`의 규칙대로 한 번만 확인한다.

## 6단계: 종합 보고
| 단계 | 결과 | 내용 |
|------|------|------|
| 1. 기록 수집 | ✅/❌ | 학생 수, 기록 수 |
| 2. 학급 성적표 | ✅/❌ | 학급 평균 정답률 |
| 3. 약점 분석 | ✅/❌ | 가장 약한 카테고리 |
| 4. 학생 비교 | ✅/⏭️/❌ | 비교한 학생 |
| 5. 개인 성적표 | ✅/⏭️/❌ | 만든 파일 수 |

이어서 **선생님이 다음에 할 일**을 3개 이내로 제안한다. (예: "과학 easy를 민수·지은에게 과제로 내기", "`/quiz-add 과학 easy`로 문제 보강", "기록 없는 학생 2명에게 기록 내보내기 안내")

## 실패 보고 형식
| 항목 | 내용 |
|------|------|
| 실패한 단계 | |
| 실패 원인 | 오류 메시지 원문, 문제가 된 파일 |
| 파일 상태 | 만들거나 바꾼 파일 |
| 해결 방법 | 사용자가 할 수 있는 조치 |

## 주의
- 각 명령의 "주의"를 그대로 지킨다. 소스 코드, `questions.js`, `teacher-data/raw/`의 원본 파일은 수정하지 않는다.
- 계산에 쓴 임시 스크립트는 프로젝트 폴더가 아니라 스크래치패드에 만든다.
