`/teacher-report`로 만든 개인 성적표를 CSV 또는 PDF로 저장해줘.

## 입력값
- 전체 입력: `$ARGUMENTS` (공백으로 나누고 따옴표 제거)
- 마지막 값이 형식이다: `csv` 또는 `pdf` (대소문자 무시). 둘 다 아니면 실행하지 말고 사용 예(`/export-report 민수 pdf`, `/export-report all csv`, `/export-report teacher-data/reports/민수-20261025.md pdf`)를 보여준다.
- 남은 값이 대상이다.
  - `.md`로 끝나는 경로면 그 파일 하나
  - `all`이면 `teacher-data/reports/` 안의 모든 `.md` 파일 (하위 폴더는 읽지 않는다)
  - 그 밖에는 학생 이름. `teacher-data/reports/<학생이름>-YYYYMMDD.md` 중 날짜가 가장 최근인 파일 하나
- 대상이 비어 있으면 실행하지 말고 사용 예를 보여준다.

## 준비
- `teacher-data/reports/`가 없거나 대상 파일이 없으면 실행하지 말고, `/teacher-report <학생 | all>`로 성적표를 먼저 만들라고 안내한다. 학생 이름으로 찾지 못했으면 `reports/`에 있는 학생 이름 목록을 함께 보여준다.
- 읽는 파일은 `teacher-report.md`의 "성적표 내용" 형식을 따른다. 제목 `# 퀴즈 성적표 - <학생이름>`이 없는 파일은 성적표가 아닌 것으로 보고 건너뛴 뒤 보고한다.

## 만들 파일
- 경로: `teacher-data/exports/<원본 파일 이름>.csv` 또는 `.pdf` (폴더가 없으면 만든다)
- 성적표 파일 하나마다 출력 파일 하나를 만든다. 여러 학생을 한 파일에 합치지 않는다. (학생에게 줄 자료에 다른 학생 성적이 섞이지 않게 하기 위함)
- 같은 이름의 파일이 이미 있으면 덮어쓰기 전에 사용자에게 확인한다. (`all`이면 겹치는 파일 목록을 한 번에 보여주고 한 번만 확인)

## CSV 형식
- 인코딩은 **UTF-8 BOM**, 줄바꿈은 CRLF로 저장한다. (Excel에서 한글이 깨지지 않게)
- 열: `학생,기간,구분,항목,내 기록,학급 평균`
- 성적표의 표를 한 행씩 옮긴다.
  - `## 한눈에 보기` 표 → 구분 `한눈에 보기`
  - `## 카테고리별 정답률` 표 → 구분 `카테고리별 정답률`. 그래프 칸(`█`)은 넣지 않는다. "아직 기록이 적어요"인 칸은 그 문구를 그대로 넣는다.
- 표가 아닌 문장(성장, 잘하는 점, 더 연습할 점, 선생님 한마디)은 구분 `메모`, 항목에 소제목, `내 기록`에 문장을 넣는다. 비어 있으면 행을 만들지 않는다.
- 값에 쉼표, 큰따옴표, 줄바꿈이 있으면 큰따옴표로 감싸고, 안의 큰따옴표는 두 번 쓴다.
- `%`, `초` 같은 단위는 원문 그대로 둔다. (숫자만 빼내 바꾸지 않는다)

## PDF 형식
1. 성적표 Markdown을 HTML로 바꾼다. 제목, 표, 목록, 문단, 굵은 글씨만 처리하면 된다.
   - 글꼴은 `'Malgun Gothic', sans-serif`, 용지는 A4 세로 (`@page { size: A4; margin: 15mm }`)
   - 표에 테두리를 넣고, `█` 그래프가 줄바꿈되지 않게 한다. 표가 페이지 사이에서 잘리지 않게 `page-break-inside: avoid`를 넣는다.
   - 변환한 HTML은 스크래치패드에 둔다.
2. 헤드리스 브라우저로 PDF를 만든다. 아래 순서로 처음 찾은 것을 쓴다.
   - `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`
   - `C:\Program Files\Google\Chrome\Application\chrome.exe`
   - 명령: `<브라우저> --headless --disable-gpu --no-pdf-header-footer --print-to-pdf="<출력 경로>" "file:///<HTML 경로>"`
   - 둘 다 없으면 PDF를 만들지 말고, 브라우저가 없다고 알린 뒤 `csv`로 다시 실행하라고 안내한다.

## 검증
- CSV: 저장한 파일을 다시 읽어 BOM이 있는지, 행 수(머리글 제외)가 성적표의 표 행 수 + 메모 행 수와 같은지 확인한다.
- PDF: 파일이 있고 크기가 0보다 크며 `%PDF`로 시작하는지 확인한다.
- 실패한 파일은 지우고 실패 이유를 보고한다.

## 출력 형식 (대화창)
1. 만든 파일 목록: 학생 | 원본 성적표 | 출력 파일 | 크기
2. 건너뛴 파일: 덮어쓰지 않은 파일, 성적표 형식이 아닌 파일, 검증 실패 (이유와 함께)
3. CSV이고 대상이 한 명이면 처음 10행을 보여준다.

## 주의
- 만들거나 바꾸는 파일은 `teacher-data/exports/` 안의 파일뿐이다. 성적표 원본(`reports/`), 학급 데이터, 소스 코드는 수정하지 않는다.
- 계산·변환에 쓴 임시 스크립트와 HTML은 스크래치패드에 만든다.
- 학생 성적이 들어 있으므로 `.gitignore`에 `teacher-data/`가 있는지 확인하고, 없으면 `/teacher-collect`를 실행하면 추가된다고 알린다. (이 명령은 `.gitignore`를 수정하지 않는다)
